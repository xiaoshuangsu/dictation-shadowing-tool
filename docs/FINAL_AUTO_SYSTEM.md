## 🚀 技术实现

### 创建的文件

| 文件 | 功能 |
|------|------|
| `scripts/add_youtube_video.sh` | 一键添加脚本（Shell 包装） |
| `scripts/youtube_to_supabase.py` | 核心自动化脚本（Python） |

### 核心功能

#### 1. YouTube 下载
```python
# 使用 yt-dlp 下载视频
yt-dlp -f bestvideo+bestaudio --merge-output-format mp4
```

#### 2. 字幕提取
```python
# 下载英文字幕
yt-dlp --write-sub --sub-lang en

# 解析 VTT 格式
# 生成句子数组：[{id, text, startTime, endTime, translation}]
```

#### 3. R2 上传
```python
# 上传到 R2
s3.upload_file(bucket, key, file, ContentType='video/mp4')

# 返回 Worker URL
# https://r2-proxy.suxiaoshuang2020.workers.dev/videos/{slug}.mp4
```

#### 4. Supabase 添加
```python
# 插入到 materials 表
POST /rest/v1/materials
{
  "id": "slug",
  "title": "标题",
  "category": "分类",
  "audio_path": "R2 URL",
  "transcript": [句子数组],
  "video_url": "视频 R2 URL"
}
```
