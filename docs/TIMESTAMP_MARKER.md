# Timestamp Marker Tool (时间戳标记工具)

独立的时间戳调整工具，用于手动调整素材的分句和时间戳。

## 访问地址

- **开发环境**: http://localhost:3000/tools/timestamp-marker
- **生产环境**: https://xiaoshuangsu.github.io/dictation-shadowing-tool/tools/timestamp-marker

## 功能特性

### 核心功能
1. **素材加载**: 通过素材标题从数据库加载
2. **音频播放**: 内置音频播放器，实时显示当前时间
3. **时间戳标记**:
   - 点击句子标记开始时间
   - 双击句子标记结束时间
   - 实时高亮当前播放的句子
4. **文本编辑**: 点击句子可编辑英文和翻译
5. **自动翻译**: 集成翻译 API 自动生成中文翻译
6. **数据库保存**: 一键保存到 Supabase

### 编辑功能
- **标记开始时间**: 单击句子
- **标记结束时间**: 双击句子（或使用按钮）
- **编辑文本**: 点击句子进入编辑模式
- **删除句子**: 选中后按删除按钮
- **插入句子**: 在当前位置插入新句子
- **移动句子**: 上移/下移调整顺序

### 数据验证
- 自动检测空句子
- 时间戳重叠检测
- 时间戳连续性验证

## 使用方法

### 1. 加载素材
1. 在输入框中输入素材的完整标题
2. 点击 "Load" 按钮
3. 等待素材加载完成

### 2. 标记时间戳
1. **标记开始**: 单击句子列表中的句子
2. **标记结束**: 双击句子，或点击 "Mark End" 按钮
3. **微调**: 可以手动编辑时间戳（格式：秒，如 1.23）

### 3. 编辑内容
- 点击句子进入编辑模式
- 修改英文文本和中文翻译
- 点击 "🤖 自动翻译" 生成翻译

### 4. 保存
- 检查所有修改是否正确
- 点击 "💾 Save to Database" 按钮
- 等待保存完成提示

## 技术实现

- **位置**: `src/app/tools/timestamp-marker/page.tsx`
- **类型**: 客户端组件 ("use client")
- **数据源**: Supabase materials 表
- **样式**: Tailwind CSS
- **API**: `/api/update-transcript` (保存数据)

## 注意事项

1. **素材标题**: 必须输入完整且准确的标题（区分大小写）
2. **时间戳格式**: 使用秒为单位，支持小数点（如 1.23）
3. **自动保存**: 只有点击保存按钮才会更新数据库
4. **数据验证**: 保存前会自动验证时间戳的连续性和重叠

## 故障排除

### 问题：无法加载素材
- 确认素材标题完全匹配（包括空格和标点）
- 检查浏览器控制台是否有错误信息
- 确认数据库连接正常

### 问题：音频无法播放
- 检查音频文件是否存在
- 尝试刷新页面
- 确认网络连接正常

### 问题：保存失败
- 检查控制台错误信息
- 确认 Supabase 配置正确
- 验证是否有写入权限
