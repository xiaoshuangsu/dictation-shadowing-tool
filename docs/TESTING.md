## 🔍 日志系统

### 如何查看日志

1. **查看日志**：
   - 页面右下角有一个圆形按钮 🔍
   - 点击打开日志查看器
   - 红色圆点表示有错误日志

2. **日志类型**：
   - 🔴 ERROR：错误（功能失败）
   - 🟡 WARN：警告（不影响使用）
   - 🔵 INFO：信息（正常操作）
   - 🟢 DEBUG：调试（开发信息）

3. **日志功能**：
   - **刷新**：获取最新日志
   - **过滤**：按类型筛选
   - **下载**：导出为 JSON 文件

### 如何提交反馈

**方式 1：截图 + 日志（推荐）**
1. 打开日志查看器（右下角 🔍 按钮）
2. 点击 "📥 下载日志" 按钮
3. 截图问题界面
4. 将日志文件和截图一起发送给我

**方式 2：文字描述**
请包含以下信息：
- 发生了什么问题
- 在哪个页面/素材
- 预期行为是什么
- 实际发生了什么
- 浏览器类型和版本

## 🐛 常见问题

### Q: 音频无法播放
**A**:
1. 检查网络连接
2. 刷新页面重试
3. 查看日志中的错误信息

### Q: 语音识别不准确
**A**:
1. 这可能是正常现象（AI 识别有误差）
2. 尝试清晰地、缓慢地朗读
3. 在安静环境中测试

### Q: 时间戳不准确
**A**:
1. 这确实是一个已知问题（约 10% 的素材）
2. 开发者正在修复
3. 请记录哪些素材的时间戳有问题

1. **测试顺序**：
