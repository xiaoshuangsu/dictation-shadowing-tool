
参考 Parroto.app 的设计美学，构建一个响应式、高性能的英语学习工具首页。使用 React + Tailwind CSS，并配合 Framer Motion 实现平滑的交互动画。

## 一、 视觉设计系统 (Visual System)

配色方案： * 主色： 纯净蓝 (#2563EB) 或 深靛蓝，用于行动按钮和关键图标。
背景： 极简白背景 (#FFFFFF) 配以极其浅淡的灰色 (#F8FAFC) 作为板块区分。
辅助色： 成功绿（纠音正确）、警告红（纠音错误）、柔和紫（进度追踪）。
圆角与阴影： 所有卡片和按钮使用 rounded-2xl (16px) 或 rounded-3xl (24px)。使用 shadow-sm 并在悬停时变为 shadow-xl，营造轻盈的悬浮感。
字体： 优先选择 Inter 或 Geist 等现代无衬线字体。标题加粗 (font-bold)，正文行高设定为 leading-relaxed 以增加易读性。

## 二、 页面板块与布局要求

1. 英雄区 (Hero Section)
布局： 两栏布局。左侧放置 H1 标题 + 副标题 + 主行动按钮 (CTA)；右侧放置一个模拟 App 影子跟读界面的 UI 模型（包含音波图和录音按钮）。

2. 核心流程 (How It Works - 4个步骤)
布局： 水平四栏。
视觉： 为每个步骤配上 Lucide 图标（搜索、耳机、麦克风、折线图）。

3. 核心功能深度展示 (Core Features)
按照以下 “交替排列” 的逻辑实现四大核心功能板块，每个板块需包含一个标题、一段副标题说明，以及一个 “高保真 CSS 模拟 UI 容器”。

1. [左文右图] 听写模块 (Dictation)
UI 模拟： 设计一个模拟听写框。上方是精简的音频波形，下方是带光标的输入区域。
细节： 模拟用户正在输入。右上角显示一个“单词/全句模式”切换开关，样式参考 Parroto 的扁平化切换器。

2. [右文左图] 影子跟读模块 (Shadowing)
UI 模拟： 模拟录音界面。中心是一个发光的录音按钮。
细节： 展示一段英文文本，文本下方带有淡淡的蓝色弧线（代表 Linking/连读 符号）。文本背景应有微弱的淡蓝色浸染效果。

3. [左文右图] AI 纠错模块 (AI Error Review)
UI 模拟： 模拟诊断分析面板。
细节： 左边是原音文本，右边是 AI 分析结果。错读单词用红色高亮并带删除线，漏读单词用灰色圆圈标注，连读建议用蓝色波浪线。这种对比感要非常直观。

4. [右文左图] 成长追踪 (Growth Tracker)
UI 模拟： 模拟个人成就面板。
细节： 包含三个磁贴：Streak Days (打卡天数)、Mins Practiced (练习时长)、Courses (已学课程)。下方配一个极简的 SVG 平滑曲线图，显示练习量的持续上升。

## 三、 关键交互要求

响应式适配： 在移动端（max-width: 1024px），所有“左文右图/右文左图”自动转换为“上图下文”的垂直堆叠布局。
动画效果： 每个板块使用 framer-motion 的 whileInView 属性。当用户向下滚动时，文字从侧边滑入，UI 模拟图从底部淡入并轻微放大。
FAQ 交互： 实现一个带过渡动画的折叠面板（Accordion）。背景色设为浅灰，点击时平滑展开答案。

四、 细节打磨 (Polishing)
按钮风格： 所有的 CTA 按钮（如 "Start for Free"）应具有渐变或实色背景，并添加 hover:scale-105 transition-transform 效果。
导航栏： 保持粘性定位 (sticky top-0)，使用毛玻璃效果 (backdrop-blur-md bg-white/80)。
